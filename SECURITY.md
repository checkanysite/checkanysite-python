# Security

## Reporting a problem

Please don't report a security problem in a public issue or pull request: everyone could read it before it is fixed.

Email hello@checkanysite.com with "Security" in the subject: the address, what you found and the steps to see it. A person reads every report and replies. How we handle reports is on [our contact page](https://checkanysite.com/contact#security), and our [security.txt](https://checkanysite.com/.well-known/security.txt) says the same.

This repository holds the Python library for the CheckAnySite API, which runs on our side: report a problem in the API the same way.
